## 📌 نبذة عامة عن المشروع (Project Overview)
نظام برمجي متكامل يعتمد على تقنيات **معالجة الصور الرقمية (DIP)** لاستقبال ثلاث صور كمدخلات:
1. صورة الرقم الأول (Operand 1 - أقل من 100)
2. صورة العملية الحسابية (Operator: `+`, `-`, `×`, `÷`)
3. صورة الرقم الثاني (Operand 2 - أقل من 100)

يقوم النظام بمعالجة الصور المشوشة عبر **خطوط أنابيب معالجة بديلة (Multi-Pipeline Fallback Strategy)**، ثم استخراج الخصائص، وتجزئة خانات الأرقام من اليسار إلى اليمين، وتطبيق التعرف الهيكلي ومطابقة القوالب الموحدة، ثم تنفيذ الحساب الرياضي الآمن **دون استخدام `eval()` نهائياً** وعرض النتيجة في واجهة رسومية عصرية وتفاعلية.

---

## 🚀 مميزات النسخة المطورة (v2 Key Features)
1. **معمارية برمجية كائنية (OOP Architecture):**
   - فصل نظيف للطبقات: محرك الفلاتر (`dip_engine.py`)، منسق خطوط الأنابيب (`pipeline_manager.py`)، مصنف الأرقام والرموز (`character_recognizer.py`)، والمحرك الحسابي (`safe_calculator.py`).
2. **استراتيجية التبديل التلقائي (Fallback Mechanism):**
   - ثلاثة خطوط أنابيب (Alpha, Beta, Gamma) مع التبديل التلقائي إذا كانت الثقة أقل من 88% واختيار النتيجة الأعلى ثقة.
3. **أمان الذاكرة (Memory Immutability):**
   - حماية مصفوفات الصور الأصلية في الذاكرة وعدم التعديل عليها نهائياً أثناء المعالجة (Guideline 12).
4. **حساب رياضي موثوق وآمن:**
   - دوال صريحة للجمع والطرح والضرب والقسمة مع حظر كامل لـ `eval()`، ورصد حصري للقسمة على صفر دون أي انهيار للبرنامج.
5. **واجهة رسومية عصرية (Modern Slate UI):**
   - واجهة Tkinter مطورة ببطاقات مستقلة، إمكانية تجربة الفلاتر السريعة مباشرة (Median, Gaussian, Otsu, Morph, Canny)، شاشة عرض رقمية للمعادلة، ومستعرض كامل لأشرطة مراحل المعالجة (Pipeline Inspector).
6. **جناح اختبارات آلي بنسبة نجاح 100%:**
   - فحص العمليات الحسابية، فحص كافة الأرقام الـ 9 المشوشة، فحص كافة العمليات الـ 4، وفحص عدم تعديل الذاكرة.
7. **تقرير تسليم أكاديمي جاهز (Word Document):**
   - تقرير شامل منسق بالكامل `DIP_Project_Report_V2.docx` جاهز للتسليم للأستاذ المشرف.

## 📂 هيكلية ملفات المشروع (Directory Structure)
```
submission_dip_v2/
├── app.py                      # واجهة المستخدم الرسومية التفاعلية الحديثة
├── dip_engine.py               # محرك فلاتر معالجة الصور الرقمية واستخراج الخصائص
├── pipeline_manager.py         # إدارة وتنسيق خطوط الأنابيب البديلة (Alpha, Beta, Gamma)
├── character_recognizer.py     # مصنف وتجزئة الأرقام والتعرف الهيكلي على العمليات
├── safe_calculator.py          # المحرك الرياضي الآمن بدون eval() ومعالجة القسمة على صفر
├── processor.py                # المنسق الشامل الذي يربط خطوط الأنابيب بالتعرف والحساب
├── visualizer.py               # أدوات رسم مربعات التحديد وتوليد شريط مراحل المعالجة
├── dataset_generator.py        # مولد القوالب وحزمة الأرقام والعمليات الجديدة مع الضوضاء
├── run_tests.py                # جناح الفحص والتحقق الآلي الشامل (100% Pass)
├── generate_final_report.py    # مولد تقرير الوورد الأكاديمي الشامل
├── DIP_Project_Report_V2.docx  # التقرير التوثيقي الجاهز للتسليم للأستاذ المشرف
├── templates/                  # قوالب الأرقام (0..9) والعمليات (+, -, ×, ÷)
├── input/                      # حزمة صور الأرقام والعمليات (النظيفة والمشوشة)
└── output/                     # مخرجات صور الكود الملونة وأشرطة مراحل المعالجة
```

## 💻 طريقة التشغيل والاستخدام (How to Run)

### 1. تشغيل الواجهة الرسومية (GUI App):
```bash
python app.py
```
- يمكنك النقر على **"📁 اختيار صورة"** لتحميل أي صورة من جهازك.
- أو النقر على **"🎲 عينة"** لتحميل عينة مشوشة عشوائية من مجلد `input/`.
- يمكنك تجربة أي فلتر رقمي بالنقر على أزرار **Quick Filters** (Median, Gaussian, Otsu, Morph, Canny).
- اضغط الزر الأخضر **"⚡ معالجة وحساب التعبير الرياضي"** لعرض النتيجة وتفاصيل درجات الثقة ومراحل المعالجة.

### 2. تشغيل جناح الاختبارات الآلي (Automated Tests):
```bash
python run_tests.py
```
يقوم بفحص جميع حالات النظام والتأكد من اجتياز الاختبارات الـ 5 بنسبة 100%.

### 3. إعادة توليد القوالب والبيانات (Optional):
```bash
python dataset_generator.py
```

### 4. إعادة بناء تقرير الوورد للتسليم (Optional):
```bash
python generate_final_report.py
```
